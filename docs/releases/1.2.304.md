1. Preserve current low-quality identifiers (`480p-low`, `360p`).
2. Persist/reset explicit detail audio choices, serialize writes with rollback, and preserve audio/subtitle intent across quality/source changes.
3. Match Auto subtitles against actual audio and the effective subtitle language; unknown audio is never replaced by the profile display language.
4. Preserve inherited forced-subtitle settings when saving an ordinary subtitle choice.
5. Use current Favorites/Watchlist membership endpoints with captured-owner capability caching and older-server fallback.
6. Remove unsupported series lifecycle-status editing from the metadata dialog.
7. Add capability-gated connection measurement, learned Auto limits, buffering-quality consent/settings, scoped recovery and plan telemetry. Distinguish terminal/no-byte outage from historical retries so slow-but-live media can accumulate real stall history.
8. Complete Server Collections listing, paged grid/Load more, partial failure handling and library invalidation.
9. Add capability-gated episode Show title query rules and preserve unknown stored rules.
10. Round-trip explicitly empty same-server Home layouts as clearing saved overrides/restoring server rows; reject damaged/missing overrides.
11. Use provider-aware Connect Apps instructions for password, directory, browser-provider and network sign-in.
12. Display contextual episode Play History labels and actual/estimated watched duration; keep the watch-time column within the native dialog viewport.
13. Remove the obsolete Send unwatched changes toggle.
14. Clamp hero synopsis to three wide/two compact lines, keeping actions visible.
15. Describe Dolby Vision+HDR10+ files' HDR10 compatibility correctly; no claim of new native Dolby Vision rendering.
16. Retain and reconcile Home's warm-return surface rather than clearing every row after playback/progress changes; verify artwork, scroll, stale refresh and authority retirement.
17. Avoid changing WinUI sidebar pane mode synchronously inside pane-transition callbacks; preserve explicit browsing state through navigation/resizing.
18. Normalize a disposed-stream exception caused by a canceled direct-read deadline, and retire a response that returns late bytes after its window expired. Deliver those bytes before retrying at the exact unread offset, including when they reset useful-progress counters. Caller cancellation sends no extra request; arbitrary disposal remains terminal.
