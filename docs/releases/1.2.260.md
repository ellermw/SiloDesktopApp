## Changes

1. Branding accent/contrast replaces the retired admin-CSS request; existing server favicon/sidebar branding and high-contrast focus behavior remain supported.
2. Capability-gated Reset Progress clears resume position and in-progress state after successful persistence, preserving played/history/list state. The DELETE is never automatically retried or refreshed. Retained detail/episode state and spoiler presentation update immediately.
3. Profile-owned device custom names support Save, Cancel, validation, pending/error/retry and null reset; reported hardware names remain visible when different.
4. Metadata-language changes retire old localized reads and caches, including saved lists, history, progress, shuffle, collections, Home, Library and pickers. Playback identity and unrelated writes are preserved; mounted Home/Library refresh through their existing seams.
5. Field-specific machine-translation provenance is retained for details, seasons, episodes and section cards. Listed-episode translation and visible Featured hero translation use the current capability/poll contract and reject retired navigation/profile/slide completions.
6. Settings uses the shared desktop sidebar, defaults to Playback, has a grouped narrow index, integrated Navigation & Cards preview, Title Pages and Language & Subtitles groups, Home-based Next Up and correct effective-setting writers. Providers start collapsed and open on a save conflict. Revision-17 episode spoiler controls now protect actual card/hero/detail/list/room/Playing Next renderers; explicit reveal, watch state and still provenance are respected. Subtitle defaults, first-layout routing and sidebar search sizing were corrected during native verification.
7. Home and Library Recommended apply recipe duplicate suppression in layout order, retain raw rows and preserve unchanged mounted references. New translation/spoiler fields participate in reconciliation so refreshed data is not discarded.
8. Episode/season menus no longer add new Favorites/Watchlist entries; existing saved entries retain Remove, without changing back into Add. Their favorite shortcut is hidden.
9. Movie/series Cast & Crew shares one ordered, deduplicated strip with current role caps, creator fallback, empty-state removal and sharper portraits.
10. Atmos labels use compatible codec/profile/title evidence, including DD+ Atmos versus TrueHD Atmos, without promoting the wrong codec family or changing default version preference.
11. Episode-list ratings retain the server's normal rating shape; no additional score badges were invented.
12. Recommendation headings, cold-start explanations and empty copy match the pinned reference; the old signal counter is removed.
13. After a native forward-only progressive remux has been paused for at least 60 seconds, resume uses the existing authoritative seek-reanchor at the current media position. Direct play, HLS, generally seekable streams and Watch Together are excluded. Local/SiloCast pause intent survives a held replacement, and a replacement committed paused starts its next idle clock.

## Evidence and limits

Implementation and test-first records are in `.codex-tmp/upstream-oct15-settings-report.md`, `upstream-oct15-media-report.md`, `upstream-oct15-home-playback-report.md` and `upstream-oct15-review-taskc-report.md`. The independent review found five integration defects; all were corrected and the follow-up source review found no remaining actionable findings. The actual MainWindow native fixture also caught the first-layout Settings default defect. Original failing logs were preserved.

The remux reproduction used actual bundled mpv, PlayerService, protocol-v3 manager, relay and a loopback MPEG-TS origin. A real 65-second pause reproduced backward replay on the old transport; the repair produced one authoritative reanchor and monotonic subsequent playback. The fixture deliberately used an eight-second write-stall window; upstream's documented default is 180 seconds. This proves the tested native failure mechanism, **not the cause or universal repair of historical recurring direct-play buffering**. Later service checks exercise actual SiloCast commands, pause/toggle during a held replan, committed FileLoaded state and a second idle resume; those advance the recorded clock rather than repeating the elapsed-time probe.

Native coverage uses isolated synthetic data and offscreen WinUI windows, including Settings at 600/1080/1920/3440/3840 widths and Cast & Crew at 460/1280/3440/3840. Rendered PNGs and protected/clear still pixels were inspected. This is scoped verification of these changes, not certification of 100% rendered parity across every existing page. Live AI-provider job completion, actual phone interoperability and live Watch Together networking are not certified. The intermittent historical Next Up removal root cause remains unresolved. The default native suite's preexisting `DetailPresentationNativeFixture.cs:55` hidden-versus-disabled assertion limitation remains; targeted native groups are used here. Existing PlayerService nullable warnings and unsigned local QA signing policy remain.
