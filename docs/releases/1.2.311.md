# 1.2.311 — Restore profile-menu and shell navigation

Local installer for owner testing. Public main, README and download remain 1.2.310. No commit, push or publication is authorized yet; the installed app remains running and unchanged.

## Scope

One correction group beyond 1.2.310. Settings used an automatic/unmeasured Frame.Width (`NaN`) to calculate a heading font size during navigation. WinUI rejected that value, interrupting Settings initialization and later sidebar detach, profile switching and logout. Subsequent Home and library navigation could also fail.

The fallback now uses the Frame's measured ActualWidth and attached viewport. Detached pages use finite zero until measured. Once mounted, the existing responsive geometry is retained. No navigation exception is swallowed and no server, auth or playback behavior is changed.

See [installed stacks, released-build reproduction and cause](../audit-gaps/2026-10-25-profile-menu-navigation.md). Official upstream main was freshly fetched at `6de6d5e5e285a9b423e95a1122cb39e5bb9ca93b`; this is a focused desktop repair, not a complete upstream alignment pass.
