# Release 1.2.516 — update dialog content stays accessible

One behavior change over published 1.2.515: keep **Check for updates** fully visible above the fixed Update now/Later footer, while release notes and preferences scroll inside a bounded body that adapts when the app window resizes. Live update-state refreshes continue to update the body without depending on its outer container type.

The regression reproduces the published 1.2.515 clipping at a 4K window: nearly the whole Check for updates button falls below the content viewport. The corrected layout checks long notes at 3840×2160, 1920×1080, 1280×720, 900×540 and 460×700, then enlarged body text, focus/scroll access to preferences and live metadata rechecking. No download or installer is triggered by the layout check.

The public 1.2.515 summary was also shortened from 1,082 to 363 characters for readability in existing clients. Its original metadata is preserved and all installer/update asset sizes and digests remain unchanged. This metadata edit adds no app behavior/version increment.

The new layout takes effect after this app version is installed. Short release summaries help existing clients display the update while they are still running their older layout. The separate progress window's Silo icon, stable main-app taskbar identity, centered keep-open update flow, subtitle continuity and prior safety protections are retained.
