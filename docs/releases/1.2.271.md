## Changes

1. **Current quality contract.** Replace retired Original/source/max choices with Auto; read canonical effective quality/bitrate under captured authority once, reuse it for source selection and session creation, and retain the hard cap through replans. Keep requested intent separate from delivered recipe. Read source dimensions/bitrate to validate source-limited tiers without the removed Original rung, with a legacy fallback. Native menus, fullscreen OSC and SiloCast share Auto/fixed choices and server display names; old cast source aliases normalize to Auto. Lists without fixed tiers do not gain an empty quality menu. Add revision20 cellular definitions/types to applicable device editors and hide deprecated choices. No Windows network guessing, bandwidth probe or new subtitle feature negotiation was introduced.
2. **Detail menus.** Group playback/library/party actions and put multiple management actions behind Manage; keep one inline. Preserve role/capability gates, current handlers and async separator visibility. Subtitle search moves to a fixed Subs footer and opens the existing dialog for the selected media file.
3. **Login recovery.** Place Forgot password below the password input, right aligned, preserving provider/capability visibility and password reveal.

Optional artwork-width adoption and HLS subtitle renditions remain separate enhancements. Compatible server-side query, notification, plugin, download, subtitle-clock and sendfile fixes need no desktop migration. See the comparison for source links and exclusions; this is not a complete historical parity/buffering certification.
