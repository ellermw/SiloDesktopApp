# 1.2.335 — update-check overlap repair

The owner authorized publishing an installer for merged PR30 and established matching installer/release delivery whenever app changes are pushed or merged to main. Release delivery is recorded in AGENTS.md.

## Cause and correction

Update Now could silently do nothing while Check for updates or a periodic release check held the update service's shared operation gate. The old download used a zero-timeout acquisition and returned immediately. It now waits with its own deadline, registers cancellation before waiting, and releases the gate only after acquisition. Playback, preference changes, Later and shutdown can still cancel/defer queued transfers.

PR30 head `e9ab1631c3f37310babd2273078639d7c83fbf7c` was merged as `0506bf20bca0ac65a3cfe9bccdf8eb1a7fba3135`; the merged tree matches the independently verified head. The original334 unit/native failures are preserved under `.codex-tmp/pr30-review-oct28/e9ab163`. This release retains the native dialog regression in source and advances the app/installer version to335.
