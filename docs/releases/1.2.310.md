## Scope

One correction group beyond 1.2.309. Clear All and individual guided-filter chip removal now save the cleared per-library state before awaiting the catalog reload. Previously these paths updated results but left the saved filters intact, causing them to return on the next visit. The issue affects the shared Library page, including Adult Scenes and other libraries.

Intentionally remembered filters, other libraries' state and the remember-library-state preference remain respected. This build does not automatically erase saved filters. After installing, clear unwanted filters once; the cleared state is then remembered.
