# 1.2.246 — Server favicon in the desktop window

This implementation is included in the local [1.2.247 installer](1.2.247.md), with the later Library cursor repair. No separate 1.2.246 installer was created. Source remains uncommitted/unpublished; the frozen 1.2.245 installer remains preserved.

The window uses the connected server's `favicon_url`, independently of the sidebar wordmark and mark. The existing server/profile hydration and branding-generation guards reject late icon completions from a retired connection. Resetting/hiding the authenticated shell restores the bundled Silo icon; absent, failed or unusable favicons also fall back to it. Nothing is specific to The Tavern.

Favicons use the existing scoped image cache. PNG/WebP and supported SVG content are converted off the UI thread into transparent Windows ICO files at 16/32/48/64/256 pixels. Existing ICO files are preserved. Converted files have immutable content names and a bounded 64-file cache. Icon download/conversion is independent of sidebar-logo loading. Failure diagnostics retain exception details in `branding.txt` with the established redaction policy.

Official Silo server main was fetched directly for this pass: `eecb7f5024249377948b50d8d65b98b4f41e9876`. Its favicon contract allows PNG/WebP/ICO/SVG and a 1 MiB upload limit. References: `web/src/contexts/BrandingProvider.tsx`, `internal/branding/assets.go`; Windows [AppWindow.SetIcon](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.windowing.appwindow.seticon?view=windows-app-sdk-1.8) and native [SVG drawing](https://microsoft.github.io/Win2D/WinUI3/html/M_Microsoft_Graphics_Canvas_CanvasDrawingSession_DrawSvg.htm). Win2D supports a subset of SVG; unsupported assets use the fallback.

Verification: Release x64 app build succeeds with the two preexisting nullable warning sites. The old 1.2.245 native fixture fails because server-icon loading is absent. The 1.2.246 fixture loads real AppWindow icons from PNG/SVG/ICO/WebP, checks converted frame sizes/source colors, distinct assets for different server scopes, and absent/404/corrupt results. The actual bundled fallback ICO is also accepted. Twenty-six focused branding/cache/regression tests pass. Evidence: `.codex-tmp/server-favicon-oct12/{red,green-pixels}`, `app-build.txt`, `focused-tests.txt`. The native fixture exercises conversion/cache and actual window icon loading; a complete live MainWindow switch between real servers has not been performed.

The user's installed 1.2.245 app was left open. This pass neither publishes an installer nor certifies complete parity, phone interoperability or resolution of the earlier intermittent removal error.
