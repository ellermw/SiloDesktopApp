# 1.2.243 — Windows SiloCast receiver

The owner installed this candidate and authorized GitHub publication on October 12, 2026. [GitHub release](https://github.com/ellermw/SiloDesktopApp/releases/tag/v1.2.243) · [Windows x64 installer](https://github.com/ellermw/SiloDesktopApp/releases/download/v1.2.243/SiloInstaller-Windows-x64.exe). Publication uses the same installer bytes without rebuilding it.

Adds opt-in SiloCast phone control to the Windows desktop app using the current official Silo protocol. The PC advertises on eligible private physical LAN interfaces, accepts authenticated phone handoffs, and plays through native libmpv in fullscreen. Remote controls include playback, seeking, audio/subtitle selection, volume and player settings. The app can receive control while minimized.

Server-approved temporary playback identity stays separate from the saved desktop account/profile. Local playback takes control back; final remote progress and session cleanup use the captured remote identity. Phone disconnection allows existing playback to continue. Disabling SiloCast, logout, identity expiry and application shutdown end remote playback and withdraw the receiver as appropriate.

Settings include receiver status and a disconnect action. The installer has an unchecked optional firewall task restricted to Private networks and the local subnet. SiloCast is disabled by default. This build does not add TV Mode or directional library navigation.
