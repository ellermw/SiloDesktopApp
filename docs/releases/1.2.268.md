## Cause and change

The actual Add Row dialog passed a 9999px uniform corner radius to a 30px-high ToggleButton. WinUI paints that oversized radius as elliptical corners, unlike CSS's proportional radius reduction. The preserved 1.2.267 native capture reproduces the reported pointed oval backgrounds; its measured 42×30px All button retains radius9999 instead of15.

Extend the existing `RoundedBadge` geometry correction from Borders to Controls. Each opted-in element clamps its radius to half its smaller measured dimension, and recalculates after resizing/text scaling. Existing padding, colors, filtering, actions and intended circular controls are preserved.

Audit corrections cover **18 sites in 13 UI source files**:

- Add Row category choices.
- Requests poster Library/Request buttons and external-title metadata badges.
- Collections library filters, Shared badges, owner initials and the collection browse action.
- Person birth date, age, death date and birthplace facts.
- External catalog count badge, book genre buttons and subtitle appearance choices.
- Watch Together people count/candidate ratings and Playing Next's Pick Another button.

Poster quality/HDR and library-media metadata badges already used the Border correction and remain covered. No instantiated raw99/999/9999/1000 corner radius remains without normalization; unused theme radius definitions are preserved. This is a source audit of the shared defect plus representative native verification, not certification of every page's full visual parity.

Official server/WebUI main was fetched directly before this pass: `f2347ace3643b1add24ff5e6514862f5f26986e0`. The separate upstream Add Row redesign is outside this shape repair.
