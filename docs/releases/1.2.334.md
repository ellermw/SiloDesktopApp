## Changes

- Incorporates all six accepted audit PRs24–29, including27's corrected real-detail/audio fixture. See [audit integration](../audit-gaps/2026-10-28-audit-prs24-29.md). PR15 was declined and closed without merging; phone control of playback started on the PC is preserved.
- Adds desktop update discovery from published stable GitHub releases, in-app release notes, a green persistent Update Available action and a green notification with View update. Both notification-only and automatic modes notify and retain manual installation access. Settings includes the same local preference and update-details action.
- Notification-only is the default. Optional automatic mode downloads while playback is idle, retains partial bytes when deferred, and installs only after a normal exit. Update Now saves/stops playback and requests a restart after successful installation. Later revokes a pending manual installation request.
- Uses the existing Windows installer. Packages require the fixed repository/asset, HTTPS, bounded size and complete SHA256 verification. A separate exit helper rechecks the package, normal-close confirmation, installed directory and other running instances. An installation gate remains held until setup actually exits, including slow setup or journal failure. Windows shutdown/logoff does not trigger installation; canceling shutdown restores ordinary update eligibility.
- Adds stage-specific update diagnostics and a next-launch installation result. Download timeouts report a retryable error. No resident updater service, server credentials or new installer option is introduced.
