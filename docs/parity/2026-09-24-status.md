For the confirmed seek gap, upstream's `web/src/lib/seekIntervals.ts` and
`web/src/hooks/queries/seekPreferences.ts` define profile-backed
`player.video_skip_back_seconds`, `player.video_skip_forward_seconds`,
`player.audiobook_skip_back_seconds` and `player.audiobook_skip_forward_seconds`.
Desktop `libs/mpv/scripts/silo-osc.lua` still uses fixed -10/+30 button skips and
±10 arrow keys. `ServerConfig` and the audiobook controls store/read local
`AudiobookSkipBackSeconds` / `AudiobookSkipForwardSeconds`. Configurable local
audio skips therefore exist, but do not satisfy the new shared-profile behavior.

## Newer upstream behavior requiring a focused comparison

The delta after the release reference also changes the following user-facing
areas. These are review targets, not claims that every desktop counterpart is
missing or broken:

- Watch Party buffering/reload/catch-up policy, lower-quality offers and routine
  reconnect notices (`web/src/player/components/VideoPlayer.tsx`,
  `hooks/useWatchTogetherPlaybackSync.ts`, `utils/roomSyncCatchup.ts`). Exercise
  host and guest clients through a continuous stall, reconnect and quality change.
- Subtitle search availability when providers are disabled, Add Subtitles dialog
  behavior/focus, and SRT placement conversion. Desktop already has the provider
  status endpoint and some UI handling; compare the reachable detail and active
  player paths before declaring a missing feature.
- History import progress and Emby Connect session handling, and server-side
  Jellyfin/Emby favorites/watch-date improvements. Check current import UI/state
  against the updated contract instead of counting server fixes as desktop work.
- Playback bitrate policy/fallback responses and “because you watched” episode
  anchors rolling up to series. Verify desktop presentation and response handling;
  server-only policy implementation does not need duplication in the player.
- Scrollable filter/overflow/Match Item dialogs. Compare bounded-height desktop
  behavior with large result sets and scaled/narrow layouts.

Administration/storage/scanner-only changes in this delta do not add desktop
scope. The native application has intentionally been user-facing since 1.1.94.
