## Remaining runtime evidence

Integration should retain explicit limits until fixtures or multi-client testing establish: a remux beginning before the room target lands while paused; reconnect retains the intended session; selection revision changes replace playback without old-session commands taking effect; transient versus sustained stalls behave correctly across the actual native loading flags; and accepting the quality offer preserves room ownership through transport replacement. These are validation boundaries, not newly confirmed defects. Root owns builds and combined verification.
