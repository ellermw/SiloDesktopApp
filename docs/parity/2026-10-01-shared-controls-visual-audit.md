## Findings affecting multiple pages

**C01 — Shared button sizing and variants differ (source-confirmed, P2).** WebUI default Button explicitly sets height 36px, padding 16px/8px, medium weight, 16px child icons, plus size variants 24/32/40px and square icon variants. Native Accent and Secondary styles set padding 16px/10px and no explicit height; Secondary also adds a border and lacks the shared medium-weight setter. Ghost uses different padding and secondary foreground. Named colors alone do not establish equivalent hover/pressed/focus behavior. Page-local setters can override these defaults and must be reviewed at each call site. Evidence: [WebUI Button](https://github.com/Silo-Server/silo-server/blob/8e2e840474a085c6df6571a5a2850f7eb996810c/web/src/components/ui/button.tsx), [native button styles](C:/Users/Michael/.codex/worktrees/parity-top-three/SiloPlayer/src/SiloPlayer/Themes/DarkTheme.xaml:357).

**C02 — Generic card padding differs (source-confirmed, P3 supplemental).** WebUI Card uses 24px vertical padding and 24px header/content/footer horizontal padding. Native CardStyle retains 12px all around. Native already defines newer 24px section tokens. Source search finds legacy CardStyle used on ServerSelect and dormant standalone HistoryPage, rather than the current sidebar Catalog history destination. This is shared-default debt, not evidence that every current card uses the wrong padding. Specialized poster/auth/settings cards override this and are covered separately. Evidence: [WebUI Card](https://github.com/Silo-Server/silo-server/blob/8e2e840474a085c6df6571a5a2850f7eb996810c/web/src/components/ui/card.tsx), [native CardStyle](C:/Users/Michael/.codex/worktrees/parity-top-three/SiloPlayer/src/SiloPlayer/Themes/DarkTheme.xaml:420), [native newer tokens](C:/Users/Michael/.codex/worktrees/parity-top-three/SiloPlayer/src/SiloPlayer/Themes/DarkTheme.xaml:155), [ServerSelect caller](C:/Users/Michael/.codex/worktrees/parity-top-three/SiloPlayer/src/SiloPlayer/Views/ServerSelectPage.xaml:92).

**C03 — Slider knob color differs (source-confirmed, P2).** WebUI thumb is background-colored with a primary border and hover/focus ring; native SliderThumbBackground is primary text color, becoming accent when pressed. Track dimensions and thumb shape remain framework-template/runtime questions; do not invent their native measurements. Evidence: [WebUI Slider](https://github.com/Silo-Server/silo-server/blob/8e2e840474a085c6df6571a5a2850f7eb996810c/web/src/components/ui/slider.tsx), [native slider brushes](C:/Users/Michael/.codex/worktrees/parity-top-three/SiloPlayer/src/SiloPlayer/Themes/DarkTheme.xaml:310).

**C04 — Dialog background defaults differ (source-confirmed, P2).** WebUI Dialog/AlertDialog use the background token; the native ContentDialog default uses SurfaceColor. Both define a 50% black scrim, which is an existing alignment. Dialog maximum width/height, close icon placement, narrow stacked footer and sheet geometry are explicit WebUI contracts; generic native brush overrides do not implement them. The Requests/account/media reports identify actual call sites where dialog and side-sheet structures differ. Evidence: [WebUI Dialog](https://github.com/Silo-Server/silo-server/blob/8e2e840474a085c6df6571a5a2850f7eb996810c/web/src/components/ui/dialog.tsx), [AlertDialog](https://github.com/Silo-Server/silo-server/blob/8e2e840474a085c6df6571a5a2850f7eb996810c/web/src/components/ui/alert-dialog.tsx), [native dialog brushes](C:/Users/Michael/.codex/worktrees/parity-top-three/SiloPlayer/src/SiloPlayer/Themes/DarkTheme.xaml:319).

**C05 — Switch off-state colors differ (source-confirmed, P2).** WebUI unchecked switch uses border fill and background knob; native off fill is SurfaceColor and knob SecondaryTextColor. Default WebUI geometry is 32×18.4px with a 16px thumb; small variant 24×14px with a 12px thumb. Native relies on Fluent geometry; its actual rendered dimensions need measurement. Evidence: [WebUI Switch](https://github.com/Silo-Server/silo-server/blob/8e2e840474a085c6df6571a5a2850f7eb996810c/web/src/components/ui/switch.tsx), [native switch brushes](C:/Users/Michael/.codex/worktrees/parity-top-three/SiloPlayer/src/SiloPlayer/Themes/DarkTheme.xaml:296).

These five groups supplement domain findings and can overlap their consequences. They are not five additional unique product bugs. Fonts, radii and several padding tokens have already been aligned in native source; none is assumed absent merely because WinUI is used.

The dynamic theme refresh preserves the cited slider/switch/dialog mappings, rather than replacing them with WebUI background/border defaults: [ThemeService.RefreshDerivedControlResources](C:/Users/Michael/.codex/worktrees/parity-top-three/SiloPlayer/src/SiloPlayer/Services/ThemeService.cs:323). Actual colors still depend on the active server theme and caller overrides.

## Repair and acceptance

Introduce/reuse native styles that implement the current contracts at shared boundaries, then convert actual callers. Avoid changing working transparent poster hit targets or decoding behavior. Record the intended semantic variant and size at each call site instead of choosing unrelated native defaults. Preserve existing font/theme/accessibility preferences.

Before accepting any converted primitive: compare both themes and branding, normal/hover/pressed/focus/selected/disabled/pending/invalid states, narrow/wide and large text/DPI, long and empty content, submenu/close/focus restoration, keyboard and UIA behavior. Then rerun representative Requests, settings and catalog captures. This audit implements none of these changes and does not certify parity.
