1. **Playback quality, revision20.** Retire Original/source/max choices in favor of Auto, preserve the configured bitrate cap, and resolve canonical effective settings under captured account/profile/device authority before both source-version selection and session start. Previously Settings wrote the canonical pair but playback read only the old profile quality column and omitted the cap. Replans retain the cap, while the UI/OSC/SiloCast distinguish requested intent from the actual delivered recipe. Current source metadata replaces the removed Original rung when validating cropped/source-limited transcodes; retain a legacy-rung fallback. Add revision20 cellular definitions/types to applicable remote-device editors, filter deprecated options, and keep the native decoder maximum independent of the screen.
2. **Detail More and Subs menus.** Playback, Library and Party groups precede management. Multiple management actions use Manage, one remains inline; preserve role/capability gates, current handlers, hidden action instances and dynamic separators. Move existing subtitle search from More to the fixed Subs footer, keeping inventory scrollable and the selected-file dialog behavior.
3. **Login recovery placement.** Move the existing capability/provider-gated Forgot password link below the password control, right aligned; preserve password reveal and recovery navigation.
