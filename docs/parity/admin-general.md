## Delivered behavior

General is registered through the production `AdminConfigureServices.Add` entry point. The shell exposes it in Configure > Server, navigation/search and Back, with page transitions suppressed. The catalog identifies all three Configure topics and 19 leaves but exposes no unfinished page. [The scope checklist](admin-configure-checklist.json) lists every leaf and its nested features; catalog coverage finishes none of the other 18 leaves. Its delivery statuses are a checkpoint before PR submission.

The page implements Identity, Network, Database and Redis in upstream order. It includes managed-field notices, secret presence without reading saved credentials, Redis enable/disable and URL/database pairing, connection checks, per-field/group dirty and restart indicators, Save/Discard and guarded departure. Returning a field to its saved value clears its dirty state. An acknowledged save updates branding from canonical saved values while retaining later editor changes, invalidates shared settings snapshots and refreshes shell restart status.

Writes use the exact displayed strong ETag once. Conflict and uncertain outcomes retain the draft and require explicit reload/review; no authentication replay or automatic write retry occurs. Redis editors freeze during saves. Failed protected-status reads hide Redis behind the official alert, retain its draft, and allow unrelated settings to save. Environment-managed Redis permits checks of saved effective values while keeping its editors disabled. Permission/profile/capability failures provide actionable recovery. Retiring authority clears private data and drafts and closes the owned dialog.

The full-width page scroller owns both gutters. Its outer frame fills the available viewport up to the shell maximum; the 1120-pixel settings column starts at that frame's left gutter, including on wide windows. Labels stay at their row's left edge, including toggle rows. Settings helpers use reference spacing/type sizes, separate field and group borders, bounded corner radii and state templates. Settings rows explicitly use `border-muted-foreground/25`, overriding the global `--input` token; this does not fix the separate theme-wide input-edge backlog. The dirty dialog owns its content-sized Cancel/Discard actions, preserves Escape as cancellation, and initially focuses Cancel. This avoids relying on native command-template rearrangement. Inputs and actions have accessible names; numeric fields request the number keyboard and retain server validation. No Enter-based submit handler interferes with IME composition.

## Resource and lifetime bounds

Effective/sensitive settings are lazily shared for 30 seconds and restart keys for five minutes. Reads retain only explicitly allowed keys and secret presence; payloads are bounded to 8 MiB. Request/probe deadlines are 15/20 seconds. Final-waiter cancellation and authority retirement cancel shared work. The page has no polling, library enumeration or whole-library prefetch. No measured latency/memory improvement is claimed.
